# 친구 요청 알림(빨간 배지) 기능 설계서

본 문서는 사용자가 새로운 친구 요청을 받았을 때, 상단 네비게이션 바의 '친구 관리' 버튼에 실시간에 준하는 방식으로 빨간 배지(대기 중인 요청 개수)를 표시하는 기능의 설계 내용을 정리한 스펙 문서입니다.

---

## 1. 개요 및 목표
*   **목표**: 사용자가 새로운 친구 요청을 받았음을 인지할 수 있도록 시각적인 피드백(빨간 배지 및 개수 표시)을 제공합니다.
*   **방식**: 백엔드 스키마 변경을 최소화하기 위해 프론트엔드 폴링(Polling) 방식을 적용합니다.
*   **주요 기능**:
    *   로그인 시 친구 목록을 호출하여 수락 대기 중인 친구 요청 개수를 배지에 반영
    *   10초 주기로 백그라운드에서 친구 요청 개수를 갱신 (폴링)
    *   친구 관리 모달을 통해 수락/거절 등 상태가 변경되면 즉시 배지 개수를 동기화
    *   로그아웃 시 폴링 타이머 해제

---

## 2. UI/UX 디자인 사양

### 상단 네비게이션 바 (App.vue)
*   **위치**: Header 내의 `👥 친구 관리` 버튼 우측 내부 혹은 우측 상단에 밀착 배치
*   **디자인**:
    *   둥근 원형 배지 형태 (`border-radius: 50%` 또는 알약 형태)
    *   배경색: `var(--danger)` (`#ef4444`, 에러/경고성 위험 빨간색)
    *   텍스트: 수락 대기 중인 요청 수 (예: `1`, `2` 등), 흰색 글씨, 작고 또렷한 폰트 크기 (`0.75rem`)
    *   표시 조건: `pendingCount > 0` 일 때만 표시

## 3. 프론트엔드 변경 내용

### 1) [App.vue](file:///c:/Users/ojm76/fastapi-vue-board/frontend/src/App.vue)
*   **상태 변수 추가**:
    *   `pendingCount`: 수락 대기 중인 친구 요청 수 (기본값 `0`)
*   **함수 추가**:
    *   `fetchPendingCount()`:
        *   로그인 상태일 때만 `getFriends()` API를 호출
        *   응답 배열에서 `status === 'PENDING'` 이며 `is_sender === false` 인 항목들의 길이를 구해 `pendingCount.value`에 저장
    *   `startPolling()` / `stopPolling()`:
        *   `setInterval`을 활용하여 10초마다 `fetchPendingCount`를 실행
        *   이미 실행 중인 타이머가 있다면 중복 생성을 방지하고, 로그아웃 또는 컴포넌트 언마운트 시 `clearInterval`을 통해 타이머 해제
*   **컴포넌트 바인딩 및 이벤트 처리**:
    *   `<FriendManagerModal>` 컴포넌트에 `@close="handleCloseFriendModal"` 또는 `@refresh="fetchPendingCount"` 바인딩을 추가하여 모달이 닫히거나 친구 수락이 완료되었을 때 배지를 즉시 갱신
    *   `isLoggedIn` 상태 변화 감지(`watch`)를 통해 로그인 시 폴링 시작, 로그아웃 시 폴링 정지 처리

### 2) [FriendManagerModal.vue](file:///c:/Users/ojm76/fastapi-vue-board/frontend/src/components/FriendManagerModal.vue)
*   **이벤트 방출(Emit)**:
    *   친구 요청을 수락(`handleAcceptFriend`)하거나 새로운 친구를 요청했을 때, 또는 모달이 닫힐 때 부모 컴포넌트에 알려 배지를 동기화할 수 있도록 커스텀 이벤트(`emit('refresh-badge')` 또는 `@close` 핸들러 연동)를 추가

## 5. 검증 계획 (테스트 시나리오)
1.  **시나리오 A (친구 요청 수신 및 배지 표시)**:
    *   `userB`로 로그인한 상태에서 다른 브라우저 또는 다른 계정(`userA`)으로 `userB`에게 친구 요청을 보냄
    *   `userB` 화면에서 최대 10초 이내에 `👥 친구 관리` 버튼 옆에 빨간색 숫자 배지 `1`이 나타나는지 확인
2.  **시나리오 B (요청 수락 시 배지 감소)**:
    *   `userB`가 `👥 친구 관리` 버튼을 눌러 모달을 연 뒤, `userA`가 보낸 요청을 '수락'함
    *   모달을 닫았을 때(또는 수락 직후) 배지가 사라지는지 확인
3.  **시나리오 C (로그아웃 및 세션 만료 시)**:
    *   로그아웃 시 폴링 타이머가 안전하게 해제되고 에러 로그가 발생하지 않는지 확인
