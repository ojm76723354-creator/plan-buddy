# 시스템 개요

## 프로젝트 명
**Plan Buddy** (협업 캘린더 플랫폼)

## 목적
사용자가 일정을 관리하고, 친구와 캘린더를 공유하며 협업할 수 있는 웹 기반 캘린더 애플리케이션 제공.

## 주요 기능 요약
- **사용자 인증**: 회원가입, 로그인, JWT 기반 세션 관리
- **캘린더 관리**: 월간/주간 뷰 제공, 개인 일정 등록/수정/삭제
- **소셜 협업**: 친구 요청/수락, 친구 캘린더 조회, **약속 초대 기능**
- **GPS 기반 위치 서비스**: 실시간 이동 경로 확인, **자동 체크인(도착 알림)**, 정시 도착률 통계 제공
- **다크 모드**: 사용자 선호에 맞춘 디자인 테마 지원

## 기술 스택 (Tech Stack)
### Frontend
- Vue 3 (Composition API)
- Tailwind CSS
- Axios, Vue Router

### Backend
- Python 3.12, FastAPI
- SQLAlchemy (ORM)
- Pydantic
- JWT, Passlib (Security)

### Database
- PostgreSQL

### Deployment
- Frontend: Vercel
- Backend: Render
