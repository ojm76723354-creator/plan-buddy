# 시스템 개요

## 프로젝트 명
**Plan Buddy** (협업 캘린더 플랫폼)

## 목적
사용자가 일정을 관리하고, 친구와 캘린더를 공유하며 협업할 수 있는 웹 기반 캘린더 애플리케이션 제공.

## 주요 기능 요약
- **사용자 인증**: 회원가입, 로그인, JWT 기반 세션 관리
- **캘린더 관리**: 월간/주간 뷰 제공, 개인 일정 등록/수정. 일정 공개 범위(PUBLIC / FRIENDS_ONLY / PRIVATE) 설정 가능
- **소셜 협업**: 친구 요청/수락, 친구 캘린더 조회(공개 범위 필터 적용), 약속 참여자 초대
- **GPS 기반 위치 서비스**: 약속 장소 지도 검색 및 핀 설정, 실시간 참여자 위치 공유, 자동 체크인(도착 알림), 정시 도착률 통계(Manner Score)
- **임시 그룹 채팅**: GPS 약속 대시보드 내 이벤트 전용 채팅방
- **다크 모드**: 사용자 선호에 맞춘 디자인 테마 지원

## 기술 스택 (Tech Stack)

### Frontend
| 항목 | 내용 |
|------|------|
| 프레임워크 | Vue 3 (Composition API) |
| 빌드 도구 | Vite 7 |
| 상태 관리 | Pinia |
| 라우터 | Vue Router 5 |
| HTTP 클라이언트 | Axios |
| 캘린더 컴포넌트 | vue-cal |
| 지도 | Naver Maps API (oapi.map.naver.com, ncpKeyId) |
| 장소 검색 | OpenStreetMap Nominatim (무료, 인증 불필요) |
| 아이콘 | Lucide Vue Next |

### Backend
| 항목 | 내용 |
|------|------|
| 언어 | Python 3.14+ |
| 프레임워크 | FastAPI 0.135+ |
| ORM | SQLAlchemy 2.0 |
| 인증 | JWT (PyJWT + bcrypt) |
| 패키지 매니저 | uv |
| 서버 | Uvicorn |

### Database
| 환경 | DB |
|------|----|
| 개발 | SQLite (`sql_app.db`) |
| 운영 | PostgreSQL |

### Deployment
| 대상 | 플랫폼 |
|------|--------|
| Frontend | Vercel |
| Backend | Render (Free Tier) |

> **주의**: Render Free Tier는 재배포 시 SQLite 파일이 초기화됩니다. 기존 사용자 데이터가 삭제되므로 운영 환경에서는 PostgreSQL 사용을 권장합니다.
