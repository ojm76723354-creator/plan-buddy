# 업무 플로우

## 1. 회원가입 및 로그인 플로우
1. 사용자가 프론트엔드에서 회원가입 폼 작성 후 제출 (`/register`).
2. 백엔드에서 데이터 유효성 검사 및 비밀번호 해싱 후 DB 저장.
3. 로그인 폼에서 이메일/비밀번호 입력 (`/login`).
4. 백엔드 검증 후 JWT 토큰 반환.
5. 프론트엔드는 토큰을 LocalStorage에 저장하고 인가(Authorization) 헤더에 포함하여 통신.

## 2. 일정 관리 플로우
1. 캘린더 뷰에서 원하는 날짜 클릭 또는 '일정 추가' 버튼 클릭.
2. 모달창에서 세부 정보 입력 후 저장.
3. `POST /events/` 호출.
4. 백엔드가 DB에 일정 추가 후 성공 응답.
5. 프론트엔드는 캘린더를 새로고침하여 새로운 일정을 렌더링.

## 3. 친구 추가 및 캘린더 공유 플로우
1. '친구 찾기' 메뉴에서 사용자 이메일 검색.
2. 친구 요청 전송 (`POST /friends/request`).
3. 상대방은 알림 또는 친구 메뉴에서 요청 확인 후 수락 (`PUT /friends/request/{id}`).
4. 수락 시 양방향 친구 관계로 설정.
5. 캘린더 뷰에서 '친구 캘린더 보기' 선택 시 친구의 일정 정보(Event 목록)를 불러와 오버레이 표시.
