# 운영 및 배포

## 3. 환경 변수 설정 (중요)

### FE (Vercel)
- `VITE_API_BASE_URL`: 백엔드 서버 주소 (예: `https://plan-buddy-zlpu.onrender.com`)
- `VITE_NAVER_MAP_CLIENT_ID`: 네이버 지도 API 클라이언트 ID

### BE (Render)
- `DATABASE_URL`: PostgreSQL 데이터베이스 연결 문자열
- `FRONTEND_URL`: 프론트엔드 배포 주소 (예: `https://plan-buddy-seven.vercel.app`)

## 4. CORS 설정 가이드
현재 배포 환경에서의 유연한 통신을 위해 백엔드(`main.py`)에서 `allow_origins=["*"]`를 적용 중입니다. 보안 고도화 시 특정 도메인(Vercel 주소)으로 제한할 수 있습니다.

## 프론트엔드 (Vercel)
- **배포 플랫폼**: Vercel
- **빌드 명령어**: `npm run build`
- **Output Directory**: `dist`
- **환경 변수**:
  - `VITE_API_BASE_URL` : 백엔드 API 서버 주소
  - **네이버 지도 API 설정**: 
    - `index.html` 내 스크립트 규격: `https://oapi.map.naver.com/openapi/v3/maps.js?ncpKeyId=YOUR_ID`
    - **통합 콘솔 필수 설정**: 네이버 클라우드 플랫폼 콘솔에서 `Web Dynamic Map` 서비스를 사용 신청하고, `Application` 설정의 `웹 서비스 URL`에 배포 도메인을 등록해야 함. (예: `https://plan-buddy-seven.vercel.app`, `plan-buddy-seven.vercel.app` 등 모든 변형 등록 권장)

## 백엔드 (Render)
- **배포 플랫폼**: Render (Web Service)
- **빌드 환경**: Python 3.x
- **빌드 명령어**: `pip install -r requirements.txt`
- **실행 명령어**: `uvicorn app.main:app --host 0.0.0.0 --port 10000`
- **환경 변수**:
  - `DATABASE_URL` : PostgreSQL 접속 URL
  - `SECRET_KEY` : JWT 암호화 키
  - `ALGORITHM` : `HS256`
  - `ACCESS_TOKEN_EXPIRE_MINUTES` : `30`

## 데이터베이스
- **호스팅**: Render PostgreSQL 또는 Supabase 등
- 배포 시 `DATABASE_URL` 환경변수를 통해 백엔드와 연결.
