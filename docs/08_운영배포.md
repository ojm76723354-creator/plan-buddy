# 운영 및 배포

## 프론트엔드 (Vercel)
- **배포 플랫폼**: Vercel
- **빌드 명령어**: `npm run build`
- **Output Directory**: `dist`
- **환경 변수**:
  - `VITE_API_BASE_URL` : 백엔드 API 서버 주소
  - **네이버 지도 API**: `frontend/index.html` 내의 인증 키(`ncpClientId`) 업데이트 필요.

## 백엔드 (Render)
- **배포 플랫폼**: Render (Web Service)
- **빌드 환경**: Python 3.x
- **빌드 명령어**: `pip install -r requirements.txt`
- **실행 명령어**: `uvicorn app.main:app --host 0.0.0.0 --port 10000`
- **환경 변수**:
  - `DATABASE_URL` : PostgreSQL 접속 URL
  - `SECRET_KEY` : JWT 암호화 키
  - `ALGORITHM` : `HS256`
  - `ACCESS_TOKEN_EXPIRE_MINUTES` : `30`

## 데이터베이스
- **호스팅**: Render PostgreSQL 또는 Supabase 등
- 배포 시 `DATABASE_URL` 환경변수를 통해 백엔드와 연결.
