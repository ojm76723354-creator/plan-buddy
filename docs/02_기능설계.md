# 기능 설계

## 1. 회원 및 인증 기능
- **회원가입**: 이메일, 닉네임, 비밀번호를 입력받아 계정 생성. 비밀번호는 해싱하여 저장.
- **로그인/로그아웃**: JWT 토큰을 발급하여 로컬 스토리지에 저장하고, 로그아웃 시 토큰 삭제.

## 2. 캘린더 및 일정 관리
- **일정 조회 (월/주간 뷰)**: 달력 형태로 날짜별 일정을 시각화.
- **일정 등록**: 제목, 시작/종료 시간, 메모 등을 입력하여 새 일정 생성.
- **일정 수정 및 삭제**: 작성자 본인만 접근 가능한 수정/삭제 권한 부여.

## 3. 친구 시스템 (소셜 기능)
- **친구 검색**: 이메일이나 이름으로 사용자 검색.
- **친구 요청 및 수락**: 특정 사용자에게 친구 요청을 보내고, 상대방이 수락(Accept)하면 친구 상태로 전환.
- **친구 캘린더 조회**: 친구로 등록된 사용자의 일정을 조회.

## 4. UI/UX 편의 기능
- **다크 모드 토글**: 밝은 테마와 어두운 테마 전환 기능.
- **반응형 디자인**: 모바일과 데스크톱 환경 모두 지원.
