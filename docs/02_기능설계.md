# 기능 설계

## 1. 회원 및 인증 기능
- **회원가입**: 이메일, 아이디(username), 비밀번호를 입력받아 계정 생성. 비밀번호는 bcrypt로 해싱하여 저장.
- **로그인/로그아웃**: JWT 토큰을 발급하여 `localStorage`의 `token`·`username` 키에 저장. 로그아웃 시 두 키 모두 삭제.
- **토큰 유효 기간**: 7일. 만료 시 재로그인 필요.

## 2. 캘린더 및 일정 관리
- **일정 조회 (월/주간 뷰)**: vue-cal 컴포넌트로 날짜별 일정 시각화. 월간 / 주간 / 일간 뷰 전환 가능.
- **일정 등록**: 제목(필수), 상세 내용, 시작/종료 시간(필수), 공개 범위 입력.
- **공개 범위 설정**: `PUBLIC`(전체 공개) / `FRIENDS_ONLY`(친구에게만 보임) / `PRIVATE`(나만 보기) 세 가지 선택.
- **GPS 약속 선택적 추가**: 일정 생성 시 "GPS 약속 추가하기" 토글을 눌렀을 때만 장소 지정 및 친구 초대 섹션 노출. 기본 일정에는 불필요.

## 3. 친구 시스템 (소셜 기능)
- **친구 검색 및 요청**: 아이디(username)로 상대방 검색 후 친구 요청 전송.
- **친구 요청 수락**: 상대방 "친구 관리" 모달에서 수락하면 `ACCEPTED` 상태로 전환.
- **미수락 요청 배지**: 상단 "친구 관리" 버튼에 미수락 건수를 빨간 배지로 표시. 30초마다 자동 폴링.
- **친구 캘린더 조회**: 캘린더 좌측 사이드바에서 친구를 선택하면 해당 친구의 일정 조회. 공개 범위 필터 자동 적용:
  - `PUBLIC` → 항상 표시
  - `FRIENDS_ONLY` → 친구 관계인 경우에만 표시
  - `PRIVATE` → 항상 숨김

## 4. GPS 기반 약속 관리 기능
- **장소 검색**: OpenStreetMap Nominatim API로 장소명·주소 검색 (역, 카페, 식당 등 POI 포함). 결과 없을 경우 네이버 지오코더로 폴백.
- **일정 장소 지정**: 네이버 지도에서 검색 결과 선택 또는 지도 직접 클릭으로 좌표 지정. 클릭 시 역지오코딩으로 주소 자동 표시.
- **도착 판정 반경**: 기본 50m, 슬라이더로 10~200m 조정 가능.
- **캘린더 내 GPS 일정 구분**: GPS 좌표가 있는 일정은 캘린더에서 초록색 배경 + 📍 아이콘으로 일반 일정과 시각적 구분.
- **참여자 초대 및 관리**: 친구 목록에서 약속 참여자를 선택하여 초대. 수락/거절 상태 추적.
- **실시간 위치 대시보드 (`/live/:id`)**: 네이버 지도에 참여자 실시간 위치 마커 표시. 5초마다 자동 폴링.
- **자동 체크인**: 참여자가 약속 장소 설정 반경 이내 진입 시 Haversine 공식으로 거리 계산 → 자동으로 `ARRIVED` 상태 업데이트.
- **정시 판정**: `arrival_time ≤ event.start_time`이면 정시 도착으로 집계.
- **임시 그룹 채팅**: 약속 전용 채팅방. 본인 메시지는 오른쪽 파란 말풍선, 상대방 메시지는 왼쪽 흰 말풍선 + 이름 표시.
- **도착 통계 (Manner Score)**: 마이페이지에 총 도착 횟수 / 정시 도착 횟수 / 약속 준수율(%) 표시.

## 5. UI/UX 편의 기능
- **다크 모드 토글**: 상단 네비게이션의 🌙/☀️ 버튼으로 테마 전환. `data-theme="dark"` 속성으로 CSS 변수 일괄 변경.
- **반응형 디자인**: 모바일과 데스크톱 환경 모두 지원.
- **마이페이지**: 프로필 사진 업로드, 닉네임 변경, 비밀번호 변경 제공.
