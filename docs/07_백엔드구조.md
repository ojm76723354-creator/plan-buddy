# 백엔드 구조

FastAPI 기반의 협업 캘린더 서비스 백엔드입니다.  
JWT 인증, 이벤트 관리, 친구 시스템, GPS 위치 추적, 임시 채팅을 제공합니다.

---

## 🛠 기술 스택

| 항목 | 내용 |
|------|------|
| 언어 | Python 3.14+ |
| 프레임워크 | FastAPI 0.135+ |
| ORM | SQLAlchemy 2.0 |
| 데이터베이스 | SQLite (개발) / PostgreSQL (운영) |
| 인증 | JWT (PyJWT + bcrypt) |
| 패키지 매니저 | uv |
| 서버 | Uvicorn |

---

## 📁 프로젝트 구조

```
backend/
├── main.py              # 앱 진입점, 미들웨어 및 라우터 등록
├── database.py          # DB 엔진 및 세션 설정
├── models.py            # SQLAlchemy ORM 모델
├── schemas.py           # Pydantic 요청/응답 스키마
├── security.py          # JWT 생성/검증, 비밀번호 해시, 현재 사용자 의존성
├── pyproject.toml       # 프로젝트 메타데이터 및 의존성
├── .env.example         # 환경 변수 예시 파일
└── routers/
    ├── __init__.py
    ├── auth_router.py       # 회원가입 / 로그인
    ├── calendar_router.py   # 이벤트 CRUD, 친구 캘린더 조회
    ├── friend_router.py     # 친구 요청 / 목록 / 수락
    ├── mypage_router.py     # 마이페이지 정보 관리
    ├── location_router.py   # GPS 위치 공유, 자동 체크인, 채팅, 통계
    └── places_router.py     # Naver Local Search API 프록시 (장소 검색)
```

## 📋 주요 모델 (`models.py`)

| 모델 | 설명 |
|------|------|
| `User` | 사용자 계정 (username, email, hashed_password, profile_image) |
| `Event` | 일정 (title, location, latitude, longitude, radius, visibility, start_time, end_time) |
| `EventParticipant` | 약속 참여자 (status, last_latitude, last_longitude, is_sharing_location, arrival_time) |
| `Friendship` | 친구 관계 (user_id_1, user_id_2, status: PENDING/ACCEPTED) |
| `EventChat` | 임시 채팅 메시지 (event_id, user_id, message, created_at) |

**`ParticipantStatus`**: `PENDING` → `ACCEPTED` / `REJECTED` / `ARRIVED`  
**`EventVisibility`**: `PUBLIC` / `FRIENDS_ONLY` / `PRIVATE`

## 🧭 주요 라우터 상세

### `calendar_router.py`
- `GET /calendar/` — 내 이벤트 + 초대받은 이벤트 반환 (`joinedload`로 participants 즉시 로드)
- `POST /calendar/` — 이벤트 생성 후 `db.flush()` → 참여자 추가 → `db.commit()` → `joinedload`로 재조회하여 반환
- `GET /calendar/friends/{username}` — 공개 범위 기반 필터링 (ACCEPTED 친구: PUBLIC+FRIENDS_ONLY, 비친구: PUBLIC만)
- `_build_event_dict()` 헬퍼로 모든 응답을 명시적 dict로 직렬화 (lazy-load 이슈 방지)

### `location_router.py`
- `POST /location/{event_id}/location` — Haversine 공식으로 약속 장소와의 거리 계산 → 반경 이내 시 `ARRIVED` 자동 체크인
- `GET /location/stats/{username}` — `arrival_time ≤ event.start_time` 이면 정시 도착으로 집계

### `friend_router.py`
- `GET /friends/list` — 본인이 관여된 모든 Friendship 반환 (PENDING 포함)
- `POST /friends/{friendship_id}/accept` — `user_id_2` (수신자)만 수락 가능
- `GET /friends/pending-count` — 미수락 요청 건수 반환

## 🧭 실시간 위치 기반 시스템

- **Haversine Algorithm**: 참여자 현재 좌표와 약속 장소 좌표 사이의 거리를 계산하여 도착 여부 판별
- **Geofencing**: 서버 측에서 `radius`(기본 50m, 최대 200m) 반경 기준으로 자동 `ARRIVED` 상태 부여
- **Ephemeral Chat**: 특정 약속 ID에 종속된 임시 채팅 저장소
- **Arrival Stats**: 종료된 약속의 도착 기록을 집계하여 유저별 정시 도착 통계 산출

## 🗄️ 데이터베이스 설정

기본값은 SQLite(`sql_app.db`)를 사용합니다.  
서버 시작 시 `Base.metadata.create_all()`로 테이블이 자동 생성됩니다.

> **주의**: SQLite 사용 중 모델에 새 컬럼을 추가한 경우, `create_all()`은 기존 테이블에 컬럼을 추가하지 않습니다.  
> 개발 환경에서는 `sql_app.db` 파일을 삭제 후 재시작하거나 `ALTER TABLE`로 수동 추가가 필요합니다.

PostgreSQL로 변경하려면 `.env` 파일을 생성하세요:
```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/plan_buddy
```

## 🔑 환경 변수

`backend/.env` 파일에 설정합니다. `.env.example`을 참고하세요.

| 변수 | 설명 | 필수 |
|------|------|------|
| `DATABASE_URL` | DB 연결 문자열 (기본값: SQLite) | 선택 |
| `SECRET_KEY` | JWT 서명 키 (기본값: `campus_calendar_dev_key_1234`) | 운영 시 필수 |
| `NAVER_CLIENT_ID` | Naver Open API Client ID (places_router용) | 장소 검색 API 사용 시 |
| `NAVER_CLIENT_SECRET` | Naver Open API Client Secret | 장소 검색 API 사용 시 |

> **Naver Open API**: [developers.naver.com](https://developers.naver.com/apps/) 에서 앱 등록 후 **검색** API 활성화 시 발급.  
> 네이버 지도 API `ncpKeyId`와는 별개입니다.  
> 프론트엔드는 현재 Nominatim을 사용하므로 미설정 시에도 장소 검색 가능합니다.

## 🔐 인증 방식

- **JWT Bearer Token**, 유효 기간 7일, 알고리즘 `HS256`
- 비밀번호는 **bcrypt**로 해시 저장
