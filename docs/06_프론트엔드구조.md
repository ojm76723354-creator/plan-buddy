# 프론트엔드 구조

Vue 3 기반의 협업 캘린더 서비스 프론트엔드입니다.  
월별/주별 캘린더 뷰, 다크 모드, 친구 관리, GPS 약속, 실시간 위치 대시보드를 제공합니다.

---

## 🛠 기술 스택

| 항목 | 내용 |
|------|------|
| 프레임워크 | Vue 3 (Composition API) |
| 빌드 도구 | Vite 7 |
| 상태 관리 | Pinia |
| 라우터 | Vue Router 5 |
| HTTP 클라이언트 | Axios |
| 캘린더 컴포넌트 | vue-cal |
| 지도 | Naver Maps API (`oapi.map.naver.com`, `ncpKeyId`) |
| 장소 검색 | OpenStreetMap Nominatim (무료, 인증 불필요) |
| 아이콘 | Lucide Vue Next |
| 날짜 처리 | date-fns |

---

## 📁 프로젝트 구조

```
frontend/
├── index.html                  # HTML 진입점 (Naver Maps 스크립트 포함)
├── vite.config.js              # Vite 설정
├── package.json
└── src/
    ├── main.js                 # 앱 마운트 (Vue + Pinia + Router)
    ├── App.vue                 # 최상위 레이아웃 (네비게이션 바, 친구 관리 모달 포함)
    ├── assets/
    │   └── main.css            # 전역 스타일 (CSS 변수, 다크 모드 토큰)
    ├── router/
    │   └── index.js            # 라우트 정의 (/, /login, /mypage, /live/:id)
    ├── api/
    │   ├── auth.js             # axios 인스턴스, login/logout, localStorage 토큰 관리
    │   ├── calendar.js         # 이벤트 CRUD, 친구 캘린더 조회
    │   ├── friends.js          # 친구 요청 / 목록 / pending count API
    │   └── mypage.js           # 마이페이지 프로필 / 통계 API
    ├── components/
    │   ├── EventModal.vue          # 일정 생성/수정 모달 (GPS 토글 포함)
    │   ├── NaverMapSelector.vue    # 지도 장소 선택 컴포넌트
    │   └── FriendManagerModal.vue  # 친구 관리 모달
    └── views/
        ├── CalendarView.vue    # 메인 캘린더 화면
        ├── LoginView.vue       # 로그인 / 회원가입 화면
        ├── MyPageView.vue      # 회원 정보 및 약속 통계 화면
        └── LiveMeetingView.vue # 실시간 약속 대시보드
```

## ⚙️ 시작하기

```bash
cd frontend
npm install
npm run dev     # http://localhost:5173
```

백엔드 서버(`http://localhost:8000`)가 먼저 실행 중이어야 합니다.

## 📄 주요 화면 및 라우트

### `/` — 캘린더 뷰 (`CalendarView.vue`)
- vue-cal로 **월간 / 주간 / 일간** 뷰 전환
- 좌측 사이드바: 내 일정 / 친구 목록 선택 → 친구 캘린더 조회 가능
- **GPS 일정 시각화**: 좌표가 있는 일정은 초록색 배경 + 📍 아이콘으로 일반 일정과 구분
- 이벤트 저장 실패 시 상세 에러 메시지 출력 (401/403/422 코드별 분기)

### `/live/:id` — 실시간 대시보드 (`LiveMeetingView.vue`)
- 네이버 지도에 약속 장소 🚩 마커 + 참여자 실시간 위치 마커
- 우측 패널: 참여자 상태(PENDING/ARRIVED + 도착 시각) 목록
- 우측 패널: 약속 전용 **임시 채팅방** (본인 메시지 오른쪽 파란 말풍선)
- 5초마다 참여자 위치 및 채팅 자동 갱신
- 기기 GPS 감지 시 자동으로 위치 전송 시작

### `/mypage` — 내 정보 (`MyPageView.vue`)
- 프로필 사진 업로드 / 닉네임 / 비밀번호 변경
- **약속 통계**: 총 도착 횟수 / 정시 도착 횟수 / 약속 준수율(%) 표시

### `/login` — 로그인 / 회원가입 (`LoginView.vue`)
- 탭 전환으로 로그인 / 회원가입 전환
- 성공 시 JWT를 `localStorage.token`, 사용자명을 `localStorage.username`에 저장

## 🧩 주요 컴포넌트

### `NaverMapSelector.vue` — 지도 장소 선택기
- **장소 검색**: OpenStreetMap Nominatim API(`nominatim.openstreetmap.org/search`) 호출
  - 역, 카페, 식당, 학교 등 POI 검색 지원
  - 결과 없을 경우 Naver Maps `geocode()` API로 폴백
  - 검색 결과 드롭다운: 장소명 + 카테고리 배지 + 주소 표시
- **지도 클릭**: 역지오코딩(Naver `reverseGeocode`)으로 주소 자동 추출
- **다크 모드**: `brightness(0.92) saturate(0.9)` 필터 적용 (지도 색상 반전 없이 자연스럽게)

### `EventModal.vue` — 일정 추가/수정 모달
- 기본 정보 (제목, 내용, 시간, 공개 범위)
- **GPS 약속 토글**: "GPS 약속 추가하기" 버튼 클릭 시에만 지도 + 친구 초대 섹션 펼침
  - 기존 GPS 일정 수정 시 자동으로 섹션 열림
  - GPS 토글 끄면 location/latitude/longitude/invitees 초기화
- 저장 시 GPS 토글 상태에 따라 GPS 필드 포함 여부 결정

### `App.vue` — 전역 레이아웃
- 상단 네비게이션: 로고, 다크 모드 토글, 친구 관리, 내 정보, 로그아웃
- 미수락 친구 요청 배지: 30초마다 폴링하여 카운트 표시
- 라우트 변경 시 로그인 상태 자동 갱신

### `FriendManagerModal.vue` — 친구 관리 모달
- 아이디로 친구 요청 전송
- 친구 목록 조회 (PENDING 대기 / ACCEPTED 수락 상태 표시)
- 수락 대기 중인 요청은 수락 버튼 표시

## 🔐 인증 흐름

```
사용자 로그인 (POST /login)
    ↓
JWT + username → localStorage 저장
    ↓
axios 인터셉터가 모든 요청에 Authorization: Bearer <token> 자동 첨부
    ↓
로그아웃 시 localStorage에서 token, username 삭제
```

## 🎨 다크 모드

- `App.vue`의 🌙/☀️ 토글 버튼으로 제어
- `document.documentElement`에 `data-theme="dark"` 속성 설정/해제
- `main.css`의 CSS 변수(`--bg-color`, `--text-primary` 등)로 전체 테마 전환
- vue-cal 선택 셀 내 이벤트 가독성 보장: `.vuecal__cell--selected .vuecal__event`에 흰색 텍스트 강제 적용
- 지도 다크모드: `filter: brightness(0.92) saturate(0.9)` (색상 반전 없이 자연스럽게)
